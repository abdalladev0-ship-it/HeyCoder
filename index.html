GET STARTED IN 60 SECONDS

The app is already on this PC.

NEXUS lives in your Nexus folder. Launch it, then use Files, Terminal, Editor, and local AI in one window.

01

Open a terminal

In File Explorer go to C:\Nexus.

02

Start the desktop app

Run npm start or double-click start.bat.

03

Turn on local AI

Open the AI tab. If Ollama is missing, choose Yes and NEXUS installs it plus a small fast model.

Core desktop features are designed to work locally. Optional services such as cloud AI may require internet.
